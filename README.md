
# 🌌 DayOrbit — Your Day. Your World.

DayOrbit is a modern, responsive multi-tool website designed to bring everyday essentials together in one convenient place.

From checking weather conditions and setting alarms to tracking time and exploring Indian festivals, DayOrbit aims to make daily tasks simpler with a clean interface and an interactive user experience.

## ✨ Features

### 🌤️ Weather Dashboard
- Search for cities and view their weather conditions.
- Explore current weather details and temperature.
- View hourly and 7-day forecasts.
- Check humidity, wind, pressure, precipitation, UV index and more.
- Get practical recommendations based on weather conditions.

### ⏰ Alarm Clock
- Set an alarm using a 12-hour AM/PM time selector.
- Hear a classic two-tone alarm ringtone.
- Stop the alarm or snooze it for five minutes.
- View a live digital clock and date.

**Note:** The alarm runs in the browser. Keep the page open and your device awake; browser or device restrictions may prevent the alarm from ringing reliably.

### ⏱️ Stopwatch
- Measure elapsed time using the stopwatch interface.

### ⌛ Timer
- Use the timer for study sessions, work and daily activities.

### 📅 Indian Festival Calendar
- Navigate between months and years.
- Explore calendar dates and highlighted Indian festivals.
- Select dates and view available festival information.

### 🎨 User Interface
- DayOrbit branding and custom app icon.
- Responsive layout for desktop and mobile screens.
- Dark and light themes with saved theme preferences.
- Animated sections, interactive cards and dropdown navigation.
- Dedicated About App and About Developer pages.

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling, layouts, responsive design and animations
- **JavaScript** — Interactions and application logic
- **Bootstrap 5** — Responsive components and navigation
- **Open-Meteo API** — Weather data
- **Web Audio API** — Browser-generated alarm tones
- **Git & GitHub** — Version control and source code hosting
- **Vercel** — Website deployment

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/PransuMishra/DayOrbit.git
```

### 2. Open the project

```bash
cd DayOrbit
```

Open the folder in Visual Studio Code.

### 3. Launch the website

Use the Live Server extension in VS Code and open `index.html`.

You can then navigate through the Home page and the available tools.

## 🌐 Deployment

DayOrbit is deployed using Vercel and connected to its GitHub repository.

After pushing changes to the connected production branch, Vercel can automatically trigger a new deployment.

## 🔮 Project Goals

DayOrbit aims to provide a simple and unified experience for everyday weather checks, time management and calendar exploration.

The project also serves as a practical demonstration of frontend development, responsive UI design, JavaScript interactions and API integration.
